# LimboReconnectPlus
A reconnect queue plugin for Velocity built with [**LimboAPI**](https://github.com/Elytrium/LimboAPI).

A fork of [LimboReconnect](https://github.com/Elytrium/LimboReconnect) with reconnect queue and batching support.

## See also

- [**LimboReconnect (Original)**](https://github.com/Elytrium/LimboReconnect) - Original reconnect plugin by Elytrium.
- [**LimboQueue**](https://github.com/Elytrium/LimboQueue) - Queue plugin for [**Velocity**](https://docs.papermc.io/velocity) built with [**LimboAPI**](https://github.com/Elytrium/LimboAPI).
- [**LimboAPI**](https://github.com/Elytrium/LimboAPI) - Library for sending players to virtual servers (called limbo).

## Features

- Queue-based player reconnects after server restarts;
- Configurable batch reconnect size and delay;
- Priority groups and permission-based queue bypass;
- Custom kick trigger regex support;
- Title, BossBar, ActionBar, and TabList queue indicators;
- Grace period for reconnecting players upon disconnection;
- MiniMessage and Legacy color formatting support;

## Commands and permissions

### Admin

- ***limboreconnectplus.command.reload* | /limboreconnectplus reload** - Reload Plugin Command

## Requirements

- Latest [**Velocity**](https://docs.papermc.io/velocity)
- Latest [**LimboAPI**](https://github.com/Elytrium/LimboAPI)
